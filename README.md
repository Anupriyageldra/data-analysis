 Geospatial Parcel Shape Classification, Frontage & Setback Analysis

A GIS-based project for automated land parcel analysis using Python, GeoPandas, and Shapely.

Features

- Shape Classification:Square, Rectangle, Elongated Rectangle, and Bevelled.
- Geometric Analysis: Side lengths, area, perimeter, and compactness calculation.
- Frontage Detection:Identifies open and closed frontages using road intersections and parcel boundaries.
- Setback Calculation:Generates setback geometries using perpendicular extension and buffer-based operations.
- Visualization: Displays parcel shapes, frontage boundaries, and setback areas.

Technologies Used

- Python
- GeoPandas
- Shapely
- Pandas & NumPy
- Matplotlib & Folium

Applications

Real Estate Analytics, Property Valuation, Land Parcel Assessment, and Urban Planning.
